# Customer Behavior Analysis

A data analytics project that explores customer shopping behavior using **Python, MySQL/SQL, and Power BI**. The project follows an end-to-end workflow: loading and cleaning customer data, preparing it for analysis, answering business questions with SQL, and presenting key insights through an interactive Power BI dashboard.

## Project Overview

The goal of this project is to better understand customer purchasing behavior and identify patterns related to:

- Customer demographics
- Subscription status
- Product categories and purchasing patterns
- Revenue and sales performance
- Discounts and promotions
- Shipping preferences
- Review ratings
- Customer age groups and repeat purchases

The analysis starts with a CSV dataset containing customer shopping records. Python is used for data exploration, cleaning, and feature engineering. The processed dataset is loaded into MySQL, where SQL queries are used to answer business questions. Finally, Power BI is used to create an interactive dashboard for visual analysis.

## Dataset

The project uses a customer shopping behavior dataset containing **3,900 records and 18 original columns**.

### Key columns

| Column | Description |
|---|---|
| Customer ID | Unique identifier for each customer |
| Age | Customer age |
| Gender | Customer gender |
| Item Purchased | Product purchased |
| Category | Product category |
| Purchase Amount (USD) | Purchase value |
| Location | Customer location |
| Size | Product size |
| Color | Product color |
| Season | Season associated with the purchase |
| Review Rating | Customer review rating |
| Subscription Status | Whether the customer is subscribed |
| Shipping Type | Shipping method used |
| Discount Applied | Whether a discount was applied |
| Promo Code Used | Whether a promo code was used |
| Previous Purchases | Number of previous purchases |
| Payment Method | Payment method used |
| Frequency of Purchases | Purchase frequency |

### Data preparation performed in Python

The notebook performs the following operations:

1. Loads the CSV dataset using Pandas.
2. Explores the dataset with methods such as `head()`, `describe()`, `info()`, and missing-value checks.
3. Handles missing values in `Review Rating` by filling them with the **median review rating within the same product category**.
4. Standardizes column names by converting them to lowercase and replacing spaces with underscores.
5. Renames `purchase_amount_(usd)` to `purchase_amount`.
6. Creates an `age_group` feature using quartile-based segmentation:
   - Young_Adult
   - Adult
   - Middle_Age
   - Senior
7. Creates `purchase_frequency_days` by mapping purchase-frequency labels to approximate day values.
8. Removes `promo_code_used` after checking its relationship with `discount_applied`.
9. Uploads the processed dataset to a MySQL database named `customer_behavior`.

The original CSV contains missing values only in `Review Rating` (37 rows), which are handled in the notebook.

## SQL Analysis

The SQL script contains 10 business questions, including:

1. Total revenue generated by male vs. female customers
2. Customers who used a discount and spent at or above the average purchase amount
3. Top 5 products with the highest average review rating
4. Comparison of average purchase amounts for Standard and Express shipping
5. Comparison of subscribers and non-subscribers by customer count, average spend, and total revenue
6. Top 5 products with the highest discount application rate
7. Customer segmentation into New, Returning, and Loyal groups based on previous purchases
8. Top 3 most purchased products within each category using a window function
9. Subscription behavior among repeat buyers with more than 5 previous purchases
10. Revenue contribution by age group

The SQL queries are written against the MySQL table:

```sql
customer
```

## Getting Started

### Prerequisites

Install:

- Python 3.x
- MySQL Server
- Power BI Desktop (for the dashboard)

### 1. Clone the repository

```bash
git clone https://github.com/<your-username>/<your-repository-name>.git
cd <your-repository-name>
```

### 2. Create and activate a virtual environment (recommended)

**Windows**

```bash
python -m venv venv
venv\Scripts\activate
```

**macOS/Linux**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Python dependencies

```bash
pip install pandas sqlalchemy pymysql jupyter
```

### 4. Prepare the dataset

Either rename:

```text
customer_shopping_behavior(1).csv
```

to:

```text
customer_shopping_behavior.csv
```

or update this line in the notebook:

```python
df = pd.read_csv('customer_shopping_behavior.csv')
```

to use the actual filename.

### 5. Configure MySQL

Make sure your MySQL server is running.

The notebook connects to MySQL and creates the following database automatically if it does not already exist:

```text
customer_behavior
```

The processed dataset is uploaded to:

```text
customer
```

### 6. Update database credentials

Before running the notebook, replace the sample MySQL credentials with your own values.

For example:

```python
username = "root"
password = "YOUR_PASSWORD"
host = "localhost"
port = 3306
```

> **Security recommendation:** Do not commit real database passwords to GitHub. For a production-ready version, store credentials in environment variables or a `.env` file and add that file to `.gitignore`.

### 7. Run the Jupyter Notebook

Start Jupyter:

```bash
jupyter notebook
```

Then open:

```text
customer_shopping_behavior.ipynb
```

Run the notebook cells in order. This will load and prepare the dataset and upload the processed data to MySQL.

### 8. Run the SQL analysis

Open your preferred MySQL client and execute the queries in:

```text
customer_behavior_analysis.sql
```

Make sure the `customer_behavior` database is selected and the `customer` table has been created by the notebook first.
